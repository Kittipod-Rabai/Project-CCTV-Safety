# เอกสารนำเสนอ Project CCTV Safety

อัปเดต: 14 ตุลาคม 2026

ใช้เตรียมการนำเสนอครั้งสุดท้ายเชิงเทคนิค 15 นาที ไม่รวมถาม–ตอบ เนื้อหา 11 สไลด์ใช้เวลา 14 นาที และเผื่อเปลี่ยนหน้าจอ/รอผล 1 นาที

## ลำดับการใช้งาน

1. [เนื้อหาสไลด์](slides.md): ข้อความสำหรับนำไปวางในโปรแกรมทำสไลด์ พร้อมเวลาแต่ละช่วง
2. [บทพูดและลำดับสาธิต](speaker-notes.md): ใช้ซ้อมให้ตรงกับหมายเลขสไลด์ รวมคำตอบสำหรับคำถามที่คาดว่าจะพบ
3. [หลักฐานและสถานะงาน](evidence.md): แหล่งที่มาของตัวเลข ผลทดลอง และขอบเขตคำกล่าว
4. [แผนแก้ไข 5 งาน](improvement-plan.md): ใช้ติดตามงานที่ทำแล้วและงานที่เหลือ

## สถานะที่ใช้ในการนำเสนอ

- งาน 1 Pipeline รวมและ Live replay ทำงานจริงระดับต้นแบบบนเครื่องทดสอบ ผ่านการตรวจ CPU/CUDA ดู [รายงานงาน 1](pipeline-live-verification.md) และ commit `a616b05`
- งาน 2 SQLite/Logs บันทึกผลโมเดล อ่านประวัติ และเปลี่ยนสถานะตรวจสอบได้ โดยข้อมูลคงอยู่หลังเปิด backend ใหม่ ดู [รายงานงาน 2](history-verification.md) และ commit `472bf82`
- งาน 3 Dashboard สรุปข้อมูลจริงจาก SQLite พร้อมสถานะ Live API ผ่านการตรวจแล้ว ดู [รายงานงาน 3](dashboard-verification.md)
- งาน 4 แจ้งเหตุสงสัยภายในเว็บพร้อม cooldown และลิงก์ประวัติจริง ผ่านการตรวจแล้ว ดู [รายงานงาน 4](notifications-verification.md)
- งาน 5 ค่าตั้ง YOLO/X3D/Tracking บันทึกจริง โหลดหลัง restart และมีผลกับรอบถัดไป ผ่านการตรวจแล้ว ดู [รายงานงาน 5](settings-verification.md)
- โหมดจริง: Dashboard, Upload & Analyze, Live pilot และ Alert / Logs เรียกใช้งานจริง โหมดสาธิตใช้หน้าจอเดียวกันพร้อมข้อมูลที่เชื่อม Live → แจ้งเตือน → Logs → Dashboard และแยกที่มาของผลบันทึก/สมมติ ดู [คู่มือเดโมปัจจุบันและผลตรวจ](shared-demo-verification.md)

รายงานงาน 1 เก็บผลตรวจ ณ เวลาก่อนเพิ่มงาน 2 จำนวนทดสอบ 269 tests จึงต่างจากชุดรวมหลังงาน 2 ที่ผ่าน 285 tests หลังเพิ่มงาน 3 ชุดทดสอบรวมผ่าน 287 tests หลังงาน 4 ผ่าน 299 tests และหลังงาน 5 ผ่าน 316 tests จำนวนเหล่านี้ยืนยันการทำงานตามกรณีทดสอบ ส่วนความแม่นยำของโมเดลอ้างผล held-out test ในเอกสารหลักฐาน

## สิ่งที่ยังต้องเตรียมก่อนส่ง

- เติมชื่อสมาชิก หน้าที่ รายวิชา อาจารย์ และผู้นำเสนอ
- เทียบวัตถุประสงค์กับข้อเสนอโครงการฉบับที่ส่งอาจารย์
- เลือกภาพผลถูก/ผิด กราฟ และไฟล์เดโมที่ทีมตรวจแล้ว พร้อมบันทึกหน้าจอสำรอง
- ซ้อมบนเครื่องพรีจริงให้จบใน 15 นาที และวัดเวลาใหม่หากเปลี่ยนเครื่องหรือเงื่อนไข

ลิงก์ไปยัง `reports/`, `weights/` และ `data/processed/` บางส่วนเป็นหลักฐานในเครื่องที่ Git ignore ไว้ ผู้ที่ clone โครงการอาจเปิดไม่ได้ ให้เตรียมสำเนาหลักฐานที่จำเป็นสำหรับการนำเสนอแยกไว้ โดยไม่เพิ่มฐานข้อมูลหรือสื่อดิบเข้า commit เอกสาร

แก้เนื้อหานำเสนอในโฟลเดอร์นี้ได้โดยไม่เปลี่ยนโค้ดระบบ หากความสามารถหรือผลทดสอบเปลี่ยน ให้ปรับสไลด์ บทพูด และหลักฐานให้ตรงกัน
